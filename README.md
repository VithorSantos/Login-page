# Login Page 

Este projeto consiste em uma página de login estática e não responsiva, desenvolvida exclusivamente com HTML5 e CSS3, otimizada para a resolução de **1920x1080**.

![Site Preview](/docs/assets/sitepreview.png)

## Sobre o Projeto
O objetivo do desenvolvimento foi replicar uma interface de login moderna, praticando conceitos de estilização e posicionamento de elementos em tela fixa.

* Interface minimalista com formulário de autenticação.
* Opções de login alternativo (Google e Facebook).
* Design focado estritamente na resolução **1080p (FHD)**.

---

## Como Executar Localmente

Para baixar o projeto e abrir a página no seu computador, siga os passos abaixo:

1. Clone este repositório ou faça o download do código-fonte em formato ZIP e extraia os arquivos.
2. Navegue até a pasta `docs`.
3. Dê um duplo clique no arquivo **`index.html`** para abri-lo diretamente em qualquer navegador web (como Google Chrome, Edge ou Firefox).

> **Nota:** Como o projeto utiliza apenas HTML e CSS estáticos, não é necessário instalar nenhum servidor ou dependência externa para visualizá-lo.


## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação da página e dos formulários.
* **CSS3:** Estilização geral, fontes e posicionamento de elementos.
